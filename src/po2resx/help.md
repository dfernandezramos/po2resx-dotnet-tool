## Help

Below is the output from `po2resx -h` or `po2resx --help` as the best effort to provide
documentation for which arguments Po2Resx supports and their meaning.

```bash
Use convention to derive a SemVer product version from a GitFlow or GitHub based
repository.

po2resx [source] [destination]

    source          The path of the source PO or POT file to be transformed
    destination     The path of the RESX file to be generated
```
